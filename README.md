# 🤝 함께 배움 보드 (배움 나눔 릴레이 시스템)

## 📌 시스템 개요
학생들 간의 피드백, 질문, 도움 등 **'배움의 상호작용'을 화살표(네트워크)로 시각화**하는 온라인 캔버스입니다. 학생의 이름표(노드)를 화면에 배치하고 선을 연결하여, 학급 내에서 배움이 어떻게 흘러가고 있는지 직관적으로 파악할 수 있습니다. 상호작용이 활발한 학생을 자동으로 분석해주는 인사이트 기능을 갖추고 있습니다.

## ✨ 주요 기능
* **명단 기반 노드 생성**: 좌측 사이드바에서 학생 이름을 클릭하면 캔버스 중앙에 고유한 색상과 이모지를 가진 학생 칩(노드)이 생성됩니다.
* **실시간 참여율 트래킹**: 사이드바 하단의 프로그레스 바를 통해 전체 인원 중 몇 명이 보드에 참여(생성)했는지 한눈에 확인 가능합니다.
* **자유로운 공간 배치 (이동 모드)**: 캔버스에 생성된 학생 칩을 마우스나 터치로 자유롭게 드래그하여 원하는 구조(원형, 모둠형 등)로 배치할 수 있습니다.
* **배움 릴레이 연결 (연결 모드)**: 학생과 학생 사이를 드래그하여 '배움 화살표'를 연결할 수 있습니다. (예: A가 B에게 도움을 주었을 때 연결)
* **연결 횟수 뱃지**: 각 학생 칩 우측 상단에 몇 번의 상호작용(연결)을 받았는지 뱃지 숫자로 자동 표시됩니다.
* **나눔 왕 통계 (인사이트)**: 화살표를 가장 많이 연결한(도움을 많이 준) 학생 순으로 금, 은, 동메달과 함께 순위를 자동 집계하여 보여줍니다.

## 👩‍🏫 교사 사용 설명서 (수업 활용 가이드)

### 1. 수업 준비 및 세팅
* **명단 관리**: 좌측 상단의 톱니바퀴(⚙️) 아이콘을 눌러 학생 명단을 추가하거나 삭제합니다.
* **목표 설정**: 상단 텍스트 창에 '오늘의 배움 목표'를 입력하여 학생들의 주의를 환기합니다.
* **타이머 활용**: 상단 중앙의 타이머를 클릭하여 시간을 설정하고 재생 버튼(▶)을 눌러 제한 시간 내 활동을 독려합니다.

### 2. 보드 운영 방법
* **학생 등판**: 발표를 하거나 활동을 시작하는 학생의 이름을 사이드바에서 클릭하여 캔버스에 올립니다.
* **모드 전환 (하단 툴바)**:
  * `🖐️ 이동`: 학생 칩을 드래그하여 자리를 이동시킵니다.
  * `↗️ 배움 릴레이`: 학생 칩 사이를 드래그하여 화살표로 연결합니다.
  * *Tip: 연결된 화살표(선)를 클릭하면 해당 선만 개별적으로 삭제할 수 있습니다.*
* **선 지우기 & 초기화**: 하단 툴바를 이용해 연결된 선만 일괄 삭제하거나, 보드 전체를 깨끗하게 비울 수 있습니다.

### 3. 활동 피드백 및 평가
* 수업 말미에 하단의 **`📊 인사이트`** 버튼을 클릭합니다.
* '오늘의 배움 나눔 왕' 팝업을 띄워, 가장 활발하게 의견을 나누고 도움을 준 학생들을 다 함께 확인하고 칭찬해 줍니다.
